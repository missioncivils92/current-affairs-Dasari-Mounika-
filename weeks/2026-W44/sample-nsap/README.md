# W44 sample: Deep Dive 1, NSAP → PM Samajik Sahayata Yojana

This is the first sample written under the new selection and format rules (decisions 28–30). It is one hub segment, not a full episode: Deep Dive 1 of the W44 breadth-first rundown. Mounika chose it on 28 Oct after a 37-story triage, where it scored EYS 9.

| File | What it is |
|---|---|
| `01-research-brief.md` | Triage row and EYS, blueprint, the five steps, MCQs, the verification log and pronunciations |
| `02-master-script.md` | Two-column script for Deep Dive 1 (hub cut 841 words, about 6:28 with the two holds), plus the AP–TG Desk opening rows A.0 (checkpoint answer) and A.1 (Telugu States Lens) |
| `02b-voiceover-text.md` | Recording file, generated by `python3 tools/make_voiceover.py weeks/2026-W44/sample-nsap v1` |

## How this differs from the Oleshky sample
- **Selection:** it was picked from a scored triage table, not from momentum. India is the actor (I = 2), and every Prelims fact arises from this week's decision.
- **Prelims facts:** the whole look-alike set is on screen, with all five components and every current rate (changed and unchanged).
- **Questions:** each is in a UPSC format and is answered with a reason after the hold (rows 1.10–1.11). The checkpoint is answered at the start of the next chapter (A.0).
- **Visuals:** fact map nodes, and numbers shown at their final value.
